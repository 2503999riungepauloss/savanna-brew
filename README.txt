SAVANNA BREW CAFÉ — HTML & CSS ASSIGNMENT

PROJECT CONTENTS
- index.html: Home page
- about.html: About Us page
- menu.html: Menu with three price tables
- gallery.html: Responsive eight-image gallery
- contact.html: Contact details, opening-hours table and reservation form
- css/style.css: Shared external stylesheet
- images/: Original SVG illustrations used as self-contained image assets

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. Use the navigation to visit all five pages.

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository named savanna-brew.
2. Upload the contents of this folder (upload the files and folders, not the ZIP itself).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. After GitHub Pages finishes publishing, your website URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/savanna-brew/

IMPORTANT NOTES
- The image assets are original SVG illustrations, included locally so no image links are broken.
  They are intentionally used instead of external stock photos; you can replace them with
  suitable café photographs while keeping the same filenames/references.
- The reservation form is a front-end HTML demonstration. It uses a mailto action and therefore
  opens the visitor's email application; it does not store reservations in a database.
- Google Fonts are loaded online. Georgia and Arial fallback fonts are included in CSS.
- The external map/social links are example destinations based on the fictional assignment details.

VALIDATION
Before submission, validate each HTML page at https://validator.w3.org/ and the stylesheet at
https://jigsaw.w3.org/css-validator/. Record any remaining validator warnings here after testing.
This README does not claim that external validators have already been run.
